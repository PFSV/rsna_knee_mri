# 판독문 기반 라벨 처리 기준

## 참고 자료

* [RSNA Knee Abnormality Detection – Label 처리 관련 Discussion](https://www.kaggle.com/competitions/rsna-knee-abnormality-detection/discussion/733932)

## 핵심 내용

판독문에서 특정 소견이 **언급되지 않았다고 해서 반드시 음성으로 처리할 수 있는 것은 아니다.** 라벨마다 미언급의 의미가 다르므로, 각 라벨의 특성에 따라 처리 기준을 달리해야 한다.

* **베이커낭종(Baker’s cyst)**
  판독문에 언급되지 않았다면 실제로 음성일 가능성이 높다.

* **활막염(Synovitis)**
  판독문에 언급되지 않은 사례에서도 약 **34%가 양성**으로 확인되었다.
  따라서 `미언급 = 음성`으로 처리하면 안 되며, **관절삼출(Joint effusion)** 소견을 활용해 보완할 수 있다.

* **ACL 및 내측 반월상연골(Medial meniscus)**
  판독문에 비교적 명확하게 기술되는 소견이므로, **판독문에 나타난 판단을 그대로 라벨에 반영하는 것이 적절하다.**

## 라벨별 권장 처리 방법

| 라벨                      | 미언급 시 권장 처리                       | 관련 소견을 이용한 보완    |
| ----------------------- | --------------------------------- | ---------------- |
| **활막염**                 | 바로 음성으로 처리하지 않고 **미언급 상태 유지**     | 관절삼출 소견으로 보완 가능  |
| **슬개대퇴 골관절염(PF OA)**    | 우선 **미언급 상태 유지**                  | 보완 후보이나 별도 검증 필요 |
| **골절(Fracture)**        | **미언급 상태 유지**                     | 다른 소견으로 추정하지 않음  |
| **베이커낭종(Baker’s cyst)** | 미언급 시 음성 가능성이 높지만, 우선 판독문 기준으로 처리 | 다른 소견으로 보완하지 않음  |
| **골좌상(Bone contusion)** | **미언급 상태 유지**                     | 다른 소견으로 보완하지 않음  |
| **외측 골관절염(Lateral OA)** | **미언급 상태 유지**                     | 다른 소견으로 보완하지 않음  |
| **ACL 손상**              | 판독문의 양성·음성 표현을 그대로 반영             | 별도의 관련 소견 보완 불필요 |
| **내측 반월상연골 손상**         | 판독문의 양성·음성 표현을 그대로 반영             | 별도의 관련 소견 보완 불필요 |
